# あしもりん プライバシーポリシー

Toshihiro Funamoto（個人。以下「運営者」といいます）は、アプリ「あしもりん」（iPhone・Android。以下「本アプリ」といいます）で扱う情報について、次のとおり方針を定めます。

要点は次のとおりです。

- 全学認証の ID・パスワードと、大学のポータルから取ってきた時間割・掲示・課題は、お使いの端末の中にだけ保存します。運営者のサーバーはなく、運営者はそれらを受け取りません。
- 本アプリが通信するのは、岡山県立大学のポータル（CampusSquare）と全学認証のシステムだけです。
- 本アプリは、広告・解析・トラッキング・クラッシュの収集の仕組みを使いません。

## 1. 本アプリが扱う情報

| 情報 | 使い道 | 保存先 |
| --- | --- | --- |
| 全学認証の ID・パスワード | 大学のポータルへのログイン | 端末の中（iPhone はキーチェーン、Android は端末の暗号化された保存領域） |
| 時間割・履修している授業・掲示・課題（大学のポータルから取ってきたもの） | 今日・時間割・掲示・課題の画面の表示、検索 | 端末の中（本アプリ専用の保存領域） |
| 利用者が入力した内容（自分で足した課題、提出済みの印、掲示の印、最近の検索語など） | 画面の表示 | 端末の中（本アプリ専用の保存領域） |
| ポータルのログインの状態（Cookie） | 続けてポータルを開くため | 端末の中（本アプリの中のブラウザの保存領域） |
| 本アプリの設定（更新の間隔、規約に同意した版など） | 本アプリの動作 | 端末の中 |

これらは端末の外に送らず、運営者も受け取りません。

## 2. 通信する相手

本アプリは、利用者のログインと、時間割・掲示・課題を取ってくるために、次のシステムとだけ通信します。

- 岡山県立大学のポータル（CampusSquare。`cmps-web.oka-pu.ac.jp`）
- 岡山県立大学の全学認証のシステム（`idp.oka-pu.ac.jp`）

送るのは、ログインに必要な ID・パスワードと、ページを開くための通常の通信だけです。大学のシステムに負担をかけないよう、取りに行く間隔と回数に上限を設けています。

このほか、利用者が本アプリの中のリンク（このページや、掲示の中のリンクなど）を開いたときは、そのページを利用者の端末のブラウザで開きます。

## 3. 使わないもの

- 広告、利用状況の解析、トラッキング、クラッシュの収集の仕組みは使いません。
- 位置情報・カメラ・写真・連絡先などの許可は求めません。本アプリが使う権限は、インターネットへの接続だけです。

## 4. 端末の外に出る場合

利用者が操作したときだけ、次の情報が端末の外に出ます。

- **共有**: 掲示の画面の共有ボタンを押したときは、掲示のタイトルと掲示の URL を、利用者が選んだアプリに渡します。掲示の本文や ID は渡しません。
- **ご意見・お問い合わせ**: 本アプリの「お問い合わせ」は、GitHub の Issue のフォームを開きます。送った内容は公開され、誰でも読めます。GitHub での情報の扱いは、[GitHub のプライバシーに関する声明](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement)に従います。

本アプリの入手（App Store・Google Play）で Apple・Google が扱う情報は、それぞれの事業者の方針に従います。

## 5. 保存する期間と消し方

- 端末の中のデータは、利用者が消すまで残ります。ただし、お知らせの記録は 30 日、大学のポータルから消えた課題は 90 日たつと自動で消します。
- 設定の「ログアウト」で、ID・パスワードと、端末の中のデータをすべて消します。
- 設定の「データとストレージ」で、一部のデータだけを消せます。
- 本アプリを削除すると、端末の中のデータも消えます。ただし iPhone では、OS の仕組みにより、キーチェーンに保存した ID・パスワードが削除後も残ることがあります。確実に消すには、本アプリを削除する前に設定の「ログアウト」をしてください。

## 6. 安全のための取り組み

- ID・パスワードは、端末の OS が用意する安全な保存領域に保存します。
- 大学のシステムとの通信は暗号化（HTTPS）します。

## 7. このポリシーの変更

本アプリの機能の変更などに合わせて、このポリシーを変えることがあります。大きく変えるときは、本アプリまたはこのページでお知らせします。
