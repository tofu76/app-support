# No梗塞 プライバシーポリシー

Toshihiro Funamoto（個人。以下「運営者」といいます）は、iPhone 向けアプリ「No梗塞」（以下「本アプリ」といいます）で扱う情報について、次のとおり方針を定めます。

要点は次のとおりです。

- 本アプリに記録した内容（血圧・体重・お薬・食事・お酒・睡眠・歩数・ウォーキングのルートなど）は、お使いの iPhone の中に保存します。運営者のサーバーには送りません。運営者はそれらを受け取りません。
- 本アプリは、広告・解析・トラッキングの仕組みを使いません。
- 端末の外に出るのは、利用者が使うことを選んだ次の場合だけです。家族との共有（iCloud）、地図の表示（OpenStreetMap）、応援プランの申し込み（Apple）、ご意見・お問い合わせ（GitHub の Issue。送った内容は公開されます）。

## 1. はじめに

本アプリは、毎日の記録を通じて生活習慣を振り返る、一般向けのセルフケア支援アプリです。医療機器ではなく、診断や治療を行うものではありません。体調に不安があるときや治療については、医師などの医療者にご相談ください。

本ポリシーは、本アプリを通じて取得・利用する情報と、その取り扱いを説明します。本アプリは日本国内の利用者を対象としており、個人情報の保護に関する法律（個人情報保護法）を守って取り扱います。

## 2. 取得する情報と使い道

本アプリが扱う情報は、次のとおりです。いずれも、利用者の iPhone の中に保存し、本アプリの機能を提供するためだけに使います。

| 情報 | 使い道 | 保存先 |
| --- | --- | --- |
| 利用者が入力した記録（水分・お薬を飲んだこと・主食・お酒・たばこ・血圧と脈拍・体重・睡眠・メモ、ウォーキングの記録とふりかえり） | 今日の画面・推移・ふりかえりの表示、通知、ウィジェットへの表示 | iPhone の中（本アプリ専用の保存領域と、ウィジェットと共有する領域） |
| 設定（時間帯、目標、服薬する薬の名前、通知の入り切り、ニックネームなど） | 本アプリの動作の設定 | iPhone の中 |
| Apple ヘルスケアの記録（血圧・脈拍・睡眠・歩数・歩行距離の読み取り） | 日々の記録への取り込み | 取り込んだ値を iPhone の中の記録に保存します。ヘルスケアの元のデータは変えません |
| 位置情報（ウォーキングの計測中のみ） | ルートと距離の記録、出発地点に戻ったり行き先でとどまったりしたときの自動終了と通知 | iPhone の中（ルートの座標は 90 日たつと削除します） |
| カメラで写したもの（お薬手帳の QR、血圧計・体重計の画面） | QR の薬の情報や、画面の数値を読み取るため | 読み取ったあとの数値や薬の情報だけを保存します。写真そのものは保存せず、送信もしません |
| 利用者が話しかけた内容（Siri での服薬の記録） | 服薬を記録するため | 音声は Apple の Siri が処理します。本アプリが受け取るのは、記録の指示だけです |

### 2.1 Apple ヘルスケア（HealthKit）

- 読み取るもの: 血圧（収縮期・拡張期）、脈拍、睡眠、歩数、歩行距離。利用者が iPhone の画面で許可した項目だけです。
- 書き込むもの: 体重だけです。設定で「体重をヘルスケアに書き込む」をオンにしたときに限ります。
- ヘルスケアから得た情報は、本アプリの機能の提供のためだけに使います。広告やマーケティングには使わず、第三者に提供せず、iCloud にも保存しません。家族との共有でも、数値としては送りません。
- 許可は、iPhone の「ヘルスケア」アプリのプライバシー設定でいつでも変えられます。

### 2.2 位置情報

- ウォーキングを計測している間だけ使います。ルートと距離の記録、画面を閉じている間の記録の継続、出発地点に戻ったり行き先でとどまったりしたときの自動終了と通知のために、「常に許可」をお願いしています。
- 計測していないときは、位置情報を取得しません。
- 位置情報の許可は、iPhone の「設定」でいつでも変えられます。

### 2.3 カメラ

- お薬手帳の QR、血圧計・体重計の画面を読み取るときだけ使います。応援プランの機能です。
- 写真の文字の読み取りは、iPhone の中で行います。血圧計の写真は、読み取りのあとすぐに消します。体重計の画面は写真として保存しません。

### 2.4 通知

- 通知は iPhone の中で予約して出します。記録の時刻のお知らせ、ウォーキングの終了、ふりかえり、家族の達成や応援のお知らせ（設定でオンにしたとき）です。許可は iPhone の「設定」で変えられます。

### 2.5 Apple Intelligence（端末内の文章づくり）

- 対応機種では、今日のおすすめの歩くコースの説明、週・月のふりかえりの分析、使い方の質問への答えに、iPhone の中で動く Apple Intelligence（Foundation Models）を使います。処理は iPhone の中で完結し、記録の内容を運営者や外部のサーバーに送りません。

### 2.6 ご意見・ご要望

- 設定の「ご意見・ご要望」から、GitHub の Issue の入力フォームを開いて送れます。種類・内容と、任意で端末の情報（アプリの版・タイムゾーン）が、フォームにあらかじめ入ります。送るかどうかは、フォームで「送信」を押す利用者が決めます。送る前に、内容を直したり、端末の情報を消したりできます。
- 送った内容は、GitHub の公開ページに載り、誰でも読めます。送るには GitHub のアカウントが要ります。名前・連絡先・健康の詳しい内容（血圧の値、病名、お薬の名前など）は書かないでください。
- 本アプリは、利用者が送信するまで、ご意見の内容をどこにも送りません。いただいた内容は、お返事と改善のためにだけ使います。
- 運営者は、返信先のメールアドレスを受け取りません。お返事は、その Issue への返信として書きます。

## 3. 端末の外へ送る情報（家族との共有・Apple のサービス）

### 3.1 家族との共有（iCloud / CloudKit）

家族との共有を使うと、利用者の iCloud（Apple の CloudKit）を通じて、選んだ家族に次の情報が届きます。運営者のサーバーは通りません。使わなければ何も送りません。

- 家族に見えるもの: 今日の達成の有無、見せる範囲を「項目ごと」にしたときのチェック項目の状態（「済」「まだ」「途中」の 3 つだけ）、ニックネームの 1 文字目。見せるのは直近 2 日分です。
- 家族から届くもの: 「すごい！」「おつかれさま」「その調子」の定型の応援と、見る側のニックネームの 1 文字目。
- 送らないもの: 血圧・体重・歩数・水分量などの数値、記録の中身、続いた日数、ウォーキングのルートや位置、メモ、ヘルスケアの値。
- 登録の QR コードは 10 分だけ有効です。そのための一時的なトークン（ランダムな文字列）を iCloud の公開領域に置き、確定または取り消しのときに消します。
- 見せる相手は、利用者が QR を見せて、相手が読み取り、利用者が確かめて「見せる」を押した人だけです。
- 止めかた: 設定 › 家族と共有で、一時停止・見せる範囲の変更・共有をやめることができます。やめると、その相手への公開を止めます。

iCloud に保存された情報は Apple が運営する仕組みの中で扱われます。Apple の取り扱いは [Apple のプライバシーポリシー](https://www.apple.com/jp/legal/privacy/jp/) をご覧ください。

### 3.2 地図の表示（OpenStreetMap）

- ウォーキングのルートやおすすめのコースの地図を表示すると、表示する範囲の地図の画像（タイル）を、OpenStreetMap のタイルサーバー（tile.openstreetmap.org、OpenStreetMap Foundation が運営）から取得します。
- このとき、表示する範囲の座標（歩いた場所の周辺が分かることがあります）、お使いの端末の IP アドレス、本アプリを識別する情報（Gion.NoKosoku）がそのサーバーに届きます。記録したルートの座標の列や時刻そのものは送りません。
- 取得した地図は端末のキャッシュに最大 100 MB まで保存し、同じ場所の取り直しを減らします。

### 3.3 応援プラン（Apple の決済）

- 応援プランは、月額で自動更新される App Store のサブスクリプションです。申し込み・決済・更新・解約・返金は Apple が処理します。
- 運営者は、クレジットカードなどの支払い情報、Apple ID、氏名を受け取りません。
- 本アプリは、Apple の仕組み（StoreKit）から、応援プランの状態（加入中か、期限はいつか）だけを iPhone の中で読み取ります。運営者や外部のサーバーには送りません。

### 3.4 ご意見・お問い合わせ（GitHub）

- ご意見・お問い合わせを GitHub の Issue で送ると、Issue に書いた内容（本文、種類、端末の情報、利用者の GitHub のユーザー名、送った日時）が、GitHub（米国の GitHub, Inc.）に保管され、公開されます。運営者のサーバーは通りません。
- GitHub での取り扱いは、[GitHub のプライバシーに関する声明](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement) をご覧ください。
- 送った Issue を消したいときは、ご自身で Issue を編集・削除するか、下の「お問い合わせ」からご連絡ください。

### 3.5 Apple のその他のサービス

- iPhone の機能として Apple が処理する部分（ヘルスケア、Siri、通知の配信、iCloud、App Store）は、Apple の規約とプライバシーポリシーに従って扱われます。
- App Store のレビュー依頼の画面を、ときどき表示することがあります。表示と投稿の管理は Apple が行います。

## 4. 第三者への提供

- 運営者は、本アプリを通じて利用者の記録を取得していません。運営者が受け取るのは、利用者がご意見・お問い合わせとして Issue に書いた内容（GitHub のユーザー名、本文、任意で付けた端末の情報）だけで、これをお返事と改善のほかに使ったり、第三者に提供したりすることはありません。
- 本アプリは、広告、アクセス解析、クラッシュ収集などの外部の SDK を組み込んでおらず、利用者の追跡（トラッキング）も行いません。
- 上の 3 のとおり、利用者が使うことを選んだときに Apple・OpenStreetMap・GitHub の仕組みに情報が渡ります。
- 法令に基づく場合を除き、運営者が利用者の同意なく個人情報を第三者に提供することはありません。

## 5. 保存期間と削除

- 記録と設定は、本アプリを削除するまで iPhone の中に保存します。ウォーキングの位置情報（ルート）は、90 日たつと削除します。
- 本アプリの保存領域は iPhone のバックアップ（iCloud バックアップなど）に含まれることがあります。バックアップは Apple の仕組みで、運営者は内容を見られません。
- 個々の記録は、本アプリの画面から直したり削除したりできます。体重のヘルスケアへの書き込みを使っているときは、本アプリで消した体重はヘルスケアからも消えます。
- すべてを消すには、iPhone のホーム画面から本アプリを削除してください。端末内の記録と設定がすべて消えます。消した記録は元に戻せません。
- 家族との共有は、設定 › 家族と共有でやめられます。iCloud に置いた共有の情報の管理は、iPhone の「設定」の iCloud からもできます。
- ヘルスケアの許可と位置情報・カメラ・通知の許可は、iPhone の「設定」で取り消せます。
- 応援プランは、iPhone の「設定」›［自分の名前］›「サブスクリプション」で解約できます。

運営者は利用者の記録を保有していないため、開示・訂正・削除などのご請求の対象となる情報は、ご意見として GitHub の Issue に書かれた内容だけです。そのご請求は、下の「お問い合わせ」にお寄せください。

## 6. お子さまの利用

本アプリは、生活習慣病や脳梗塞の予防を考える成人を主な対象としています。お子さまが利用する場合は、保護者の方と一緒にご利用ください。運営者は、お子さまの個人情報を意図して取得しません。

## 7. 安全管理

- 記録は、本アプリ専用の保存領域に置き、iPhone の機能（パスコード、Face ID・Touch ID、端末の暗号化）で守られます。
- 家族との共有や地図の取得の通信は、Apple や OpenStreetMap の仕組みに従い、暗号化された通信で行います。
- iPhone に画面ロックを設定し、他の人に見られないようにしてください。

## 8. ポリシーの変更

内容を変えるときは、本ページを更新し、制定日・改定日を書き換えます。利用者に大きく影響する変更は、本アプリの中またはアプリの説明でお知らせします。
