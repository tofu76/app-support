# アスデミック プライバシーポリシー

Toshihiro Funamoto（個人。以下「運営者」といいます）は、iPhone 向けアプリ「アスデミック」（以下「本アプリ」といいます）で扱う情報について、次のとおり方針を定めます。

要点は次のとおりです。

- 本アプリに記録した内容（目標・時間割・部活の予定・勉強や睡眠の記録・テストの点数など）は、お使いの iPhone の中だけに保存します。アカウントは作らず、運営者のサーバーにも送りません。運営者はそれらを受け取りません。
- 本アプリは、インターネットに通信しません。広告・解析・クラッシュの報告・トラッキングの仕組みも使いません。
- 端末の外に出るのは、利用者が使うことを選んだ次の場合だけです。友だちとの共有（近くの端末に時間割・部活の予定を直接送る）、ご意見・お問い合わせ（GitHub の Issue。送った内容は公開されます）。

## 1. はじめに

本アプリは、部活をしている中学生・高校生が、睡眠と勉強の習慣をつくるためのアプリです。医療機器ではなく、病気の診断・治療・予防を行うものではありません。

本ポリシーは、本アプリが扱う情報と、その取り扱いを説明します。本アプリは日本国内の利用者を対象としており、個人情報の保護に関する法律（個人情報保護法）を守って取り扱います。

## 2. 扱う情報と使い道

本アプリが扱う情報は、次のとおりです。いずれも利用者の iPhone の中に保存し、本アプリの機能を提供するためだけに使います。

| 情報 | 使い道 | 保存先 |
| --- | --- | --- |
| 目標（起きる時刻、睡眠の長さ、勉強の時間） | 今日の予定の表示、達成の判定 | iPhone の中 |
| 時間割（授業の時刻、曜日と時限ごとの科目）、学校のない日 | 1 日の予定づくり | iPhone の中 |
| 部活の予定（練習の時間、土日のパターン、日ごとの予定） | 1 日の予定づくり | iPhone の中 |
| 1 日の予定（平日・土日の予定のひな形）、科目 | 今日の予定の表示、勉強の記録 | iPhone の中 |
| 勉強の配分と記録（科目・種類・時間）、睡眠の記録 | 記録中の画面、振り返り、達成カレンダー | iPhone の中 |
| テストの点数 | テスト結果の画面 | iPhone の中 |
| 所属（学校名・中学校か高校か・学年・クラス・部活） | 共有の相手が同じクラス・部活かを確かめるため | iPhone の中 |
| 設定 | 本アプリの動作の設定 | iPhone の中 |

### 2.1 Apple ヘルスケア（HealthKit）

- 読み取るもの: 睡眠の記録だけです。利用者が iPhone の画面で許可したときに限ります。
- 書き込むもの: ありません。本アプリはヘルスケアに書き込みません。
- 読み取った値は、本アプリの睡眠の記録として iPhone の中に保存し、睡眠の目標の達成を確かめるためだけに使います。広告やマーケティングには使わず、第三者に提供せず、運営者のサーバーや iCloud の保存領域（iCloud Drive など）にも送りません。友だちとの共有でも送りません。なお、iPhone のバックアップ（iCloud バックアップなど）には、本アプリの保存領域ごと含まれることがあります（5 を参照）。
- 許可は、iPhone の「ヘルスケア」アプリのプライバシー設定でいつでも変えられます。許可しなくても、睡眠は手で入力できます。

### 2.2 カメラと写真

- 時間割を撮るとき（または写真を選ぶとき）と、友だちが見せた共有の QR コードを読むときだけ使います。
- 時間割の文字の読み取りは、iPhone の中（Apple の Vision）で行います。写真は送信しません。撮った写真・選んだ写真は、読み取りのあとに消し、読み取った科目名などだけを保存します。
- 写真は、選んだ 1 枚ずつだけを読みます。写真ライブラリ全体へのアクセスは求めません。

### 2.3 Face ID・Touch ID（テスト結果のロック）

- テスト結果の画面を開くときに、本人かどうかを iPhone の仕組みで確かめます。本アプリが受け取るのは「確かめられたかどうか」だけで、顔や指紋のデータは扱いません。

## 3. 端末の外へ送る情報（友だちとの共有）

時間割と部活の予定は、「友だちと共有」で、近くにいる友だちの端末に直接送れます。インターネットや運営者のサーバーは通りません。使わなければ何も送りません。

- しくみ: 送る側の画面に出る QR コードを、受け取る側がカメラで読みます。そのあと Bluetooth で、暗号化して直接送ります。QR コードは 3 分だけ使えます。本アプリが画面に出ているときだけ動きます。
- 送るもの:
  - 時間割: 授業の時刻と、曜日・時限ごとの科目名
  - 部活の予定: 平日の練習時間、土日のパターン（記号・時間・メモ）、送る人が選んだ月の日ごとの予定
- 送らないもの: 名前、勉強・睡眠の記録、テストの点数、目標、撮った写真、所属の中身。
- 相手の確かめかた: QR コードには、学校名・学年・クラス（部活の予定では部活名）から作った短い照合のための値が入ります。受け取る側の所属と一致したときだけ受け取れます。この値は取り違えを防ぐためのもので、所属の文字そのものは入れません。ただし、学校名などの候補を当てはめていくと、所属を推測できることがあります。QR コードは、共有したい相手にだけ見せてください。
- QR コードには、名前や記録は入りません。

### 3.1 ご意見・お問い合わせ（GitHub）

- ご意見・お問い合わせを GitHub の Issue で送ると、Issue に書いた内容（本文、種類、端末の情報、利用者の GitHub のユーザー名、送った日時）が、GitHub（米国の GitHub, Inc.）に保管され、公開されます。運営者のサーバーは通りません。
- GitHub での取り扱いは、[GitHub のプライバシーに関する声明](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement) をご覧ください。
- 送った Issue を消したいときは、ご自身で Issue を編集・削除するか、下の「お問い合わせ」からご連絡ください。

## 4. 第三者への提供

- 運営者は、本アプリを通じて利用者の記録を受け取っていません。運営者が受け取るのは、利用者がご意見・お問い合わせとして Issue に書いた内容（GitHub のユーザー名、本文、任意で付けた端末の情報）だけで、これをお返事と改善のほかに使ったり、第三者に提供したりすることはありません。
- 本アプリは、広告、アクセス解析、クラッシュの収集などの外部の SDK を組み込んでおらず、利用者の追跡（トラッキング）も行いません。
- 法令に基づく場合を除き、運営者が利用者の同意なく個人情報を第三者に提供することはありません。

## 5. 保存期間と削除

- 記録と設定は、本アプリを削除するまで iPhone の中に保存します。
- 本アプリの保存領域は、iPhone のバックアップ（iCloud バックアップなど）に含まれることがあります。バックアップは Apple の仕組みで、運営者は内容を見られません。
- 個々の記録は、本アプリの画面から直したり消したりできます。
- すべてを消すには、iPhone のホーム画面から本アプリを削除してください。端末内の記録と設定がすべて消え、元に戻せません。
- 受け取った時間割・部活の予定も、受け取った人の端末の中に保存されます。消すには、受け取った人が自分の端末で消します。
- ヘルスケア・カメラ・Bluetooth の許可は、iPhone の「設定」で取り消せます。

運営者は利用者の記録を保有していないため、開示・訂正・削除などのご請求の対象となる情報は、ご意見として GitHub の Issue に書かれた内容だけです。そのご請求は、下の「お問い合わせ」にお寄せください。

## 6. お子さまの利用

本アプリは中学生・高校生を主な対象としています。運営者は、本アプリを通じて利用者の記録や個人情報を受け取らず、お子さまの個人情報を意図して取得しません。13 歳未満の方がお問い合わせ（GitHub）を使うときは、保護者の方にお願いしてください。

## 7. 安全管理

- 記録は本アプリ専用の保存領域に置き、iPhone の機能（パスコード、Face ID・Touch ID、端末の暗号化）で守られます。
- 友だちとの共有は、使い捨ての鍵で暗号化して送ります。鍵は保存しません。
- iPhone に画面ロックを設定し、他の人に見られないようにしてください。

## 8. ポリシーの変更

内容を変えるときは、本ページを更新し、制定日・改定日を書き換えます。利用者に大きく影響する変更は、本アプリの中またはアプリの説明でお知らせします。
